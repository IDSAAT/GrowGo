## 📌 About This Project

This was my very first website built from scratch using HTML, CSS, and a little JavaScript. It's an e-commerce style platform for hair products that I created as a learning project.

**Please forgive the late submission** 🙏 - I wanted to make sure I understood what I was building rather than just rushing to finish. There's still room for improvement, but I'm proud of what I've learned along the way.

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, positioning, animations)
- JavaScript (basic)
- Git & GitHub

## 📁 Project Structure
Note: create a different folder for the images called "images" to store your images in to make the structure more organized.


## ✨ Features

- Multi-page user flow (Signup → Verification → Login → Shop)
- Product listing with "Add to Cart" buttons
- Star rating system (CSS-only!)
- Responsive product grid using Flexbox
- Consistent color scheme across all pages
- Form validation on signup/login

## 🐛 Known Issues (Learning Opportunities)

- The verification code auto-focus function is still in progress
- Some images may not load without the images folder
- A few CSS selectors could be cleaner
